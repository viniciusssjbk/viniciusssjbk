## `01 / Sobre mim`

Sou estudante de **Ciência da Computação na FEI** e técnico em Informática para Internet pela ETEC Lauro Gomes.

Atualmente, faço parte do **RoboFEI Humanoide**, trabalhando com software para robôs humanoides. Também desenvolvo projetos próprios para investigar problemas na prática, desde a análise matemática da caminhada de robôs até aplicações web e sistemas de controle.

Gosto de entender o que acontece por trás de um sistema, experimentar soluções e descobrir como torná-las melhores.

> Meu objetivo é continuar explorando a computação por diferentes caminhos, especialmente robótica, sistemas embarcados e desenvolvimento de software.
